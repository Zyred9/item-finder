# 物品分类体系说明

## 分类结构

正式环境采用 **7 个简洁分类**，方便用户快速选择。

### 分类列表

| Code | 名称 | Icon | 说明 | 示例 |
|------|------|------|------|------|
| `food` | 食品饮料 | 🍔 | 所有吃的、喝的 | 牛奶、饼干、大米、酱油 |
| `medicine` | 药品健康 | 💊 | 药品、保健品 | 感冒药、维生素、血压计 |
| `clothing` | 服饰鞋包 | 👕 | 穿戴用品 | 衣服、鞋子、包包 |
| `electronics` | 数码家电 | 📱 | 电子产品、电器 | 手机、电脑、电饭煲 |
| `document` | 证件文件 | 📄 | 重要证件、文件 | 身份证、银行卡、合同 |
| `daily` | 生活用品 | 🏠 | 日用品、家居 | 洗衣液、纸巾、护肤品 |
| `other` | 其他物品 | 📦 | 不好分类的物品 | 不明物品、特殊物品 |

## 设计理念

### 为什么只用一级分类？

1. **降低选择成本** - 用户扫一眼就能找到对应分类
2. **减少决策时间** - 7 个选项比 27 个选项更容易选择
3. **符合直觉** - 家庭物品不需要太精细的分类
4. **AI 辅助** - 系统会自动识别分类，用户不需要纠结

### 分类覆盖范围

- **食品饮料**：所有入口的东西（主食、零食、饮料、调料）
- **药品健康**：治病、保健的东西（药、保健品、医疗器械）
- **服饰鞋包**：身上穿戴的（衣服、裤子、鞋子、包包）
- **数码家电**：用电的（手机、电脑、电视、电饭煲）
- **证件文件**：重要的纸质物品（证件、卡、合同、票据）
- **生活用品**：日常用的（清洁、洗漱、护肤、家居）
- **其他物品**：不好归类的都放这里

## 使用场景

### 用户存物时
系统会自动识别分类，用户只需要确认或修改：
```
物品名称：蒙牛纯牛奶
自动分类：食品饮料 ✓
存放位置：冰箱冷藏室
```

### AI 识别逻辑
系统根据物品名称关键词自动匹配分类：
- "牛奶"、"饼干"、"大米" → 食品饮料
- "感冒药"、"维生素" → 药品健康
- "T 恤"、"运动鞋" → 服饰鞋包
- "手机"、"电脑" → 数码家电
- "身份证"、"银行卡" → 证件文件
- "洗衣液"、"纸巾" → 生活用品

## 扩展字段

不同分类有不同的扩展字段（用于过期提醒）：

### 食品饮料 & 药品健康
- 生产日期
- 过期日期
- 保质期天数
- 开封日期
- 开封后保质期

### 数码家电
- 品牌
- 型号
- 购买日期
- 保修到期日期

### 服饰鞋包
- 品牌
- 尺码
- 颜色
- 材质

### 其他分类
- 备注

## 维护说明

- 分类数量保持在 5-10 个最佳
- 不要随意删除分类，会影响历史数据
- 可以调整分类名称和图标
- 分类图标文件：`miniprogram/assets/icons/`
